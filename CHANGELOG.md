# Changelog

## v1.3

- **Exit and Replay buttons during gameplay**

  - Added Exit button to return to song selection
  - Added Replay button to restart the current song

- **Enhanced keyboard controls**

  - Added support for left Control key for dit (·)
  - Added support for right Control key for dah (—)
  - Matches the behavior of [morsecode.world keyer](https://morsecode.world/international/keyer.html)

- **Right-click support for iambic buttons**

  - Dit button (·) sends dah (—) on right-click
  - Dah button (—) sends dit (·) on right-click
  - Enables flexible single-handed operation
  - Matches the behavior of [morsecode.world keyer](https://morsecode.world/international/keyer.html)

- **Improved visual feedback in Hard Mode**

  - In Hard Mode, the visualization now shows the starting point of each Morse code signal

## v1.2

- **New level: ABC**

  - This is a short song arranged specifically for this game. It's the [ABC Song](https://en.wikipedia.org/wiki/The_ABC_Song) with multiple audio cues to match the morse code signals in the level. Inspired by this [Itch.io comment](https://itch.io/post/14611800) suggesting audible cues. Also based on friend's feedback who said that a 4-minute level seems too long.

- **New level: Ophelia's Song**

  - In this level, the texts to transmit is randomized from the common word list in each playthrough. The wordlist came from [Monkeytype](https://monkeytype.com/).

- **Support using other keys on the keyboard to play**

  - Based on [YouTube comment](https://www.youtube.com/watch?v=rJ5g5MqBE8I&lc=UgyhfGK_F9qMSeLBJQZ4AaABAg) suggesting enabling full keyboard for game input.

- **Show WPM and song duration**
  - Based on [YouTube comment](https://www.youtube.com/watch?v=rJ5g5MqBE8I&lc=UgxGULAF20fGtaEBxZ94AaABAg) suggesting BPM display. Instead of BPM, we calculate the WPM (word-per-minute) based on [PARIS timing](https://morsecode.world/international/timing/).
